Issue type

secrets.insecure-default

What it means. A signing secret the application chooses itself (JWT_SECRET, SESSION_SECRET) has a sample value in an environment template or a CI configuration: an insecure default if copied, not a leaked credential.

Real fixes, by language

Each one is an edit sloptopop applied to a public repository, checked by the Guider, reviewed in its surrounding code, and linked to the file at the commit it was made on. Committed secret values are shortened, never republished.

No automatic fix for this issue type has passed review on a public repository yet. sloptopop reports it, and plans a task for a person where it can.

No reviewed fix yet in: TypeScript, JavaScript, Python, Go, Java, Kotlin, C#, C, C++, PHP, PowerShell, Rust, Shell, Swift. Examples appear here only once a fix in a real repository has passed review.

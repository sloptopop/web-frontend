deps.layering

What it means. A module imports the module that contains it: a Rust super:: import, a JavaScript import of an index.* barrel in its own or a parent directory, a Python import of its own package's __init__.py.

Why it matters. The dependency points upward, which invites cycles.

What to do. Move the shared item into a lower module that both the parent and this module import.

Automatic fix. None yet.

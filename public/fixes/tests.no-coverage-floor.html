Issue type · error

tests.no-coverage-floor

What it means. Tests run without an enforced coverage threshold (no marker such as fail-under or coverageThreshold in the files these rules read).

Why it matters. Coverage can fall without anyone deciding it should.

What to do. Set a threshold the test run enforces: Jest coverageThreshold, Vitest coverage.thresholds, c8 --check-coverage, coverage.py fail_under, or your ecosystem's equivalent.

Automatic fix. None.

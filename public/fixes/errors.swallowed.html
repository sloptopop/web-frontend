Issue type · warning

errors.swallowed

What it means. An error handler discards the error: an empty or comment-only catch block, an empty .catch(() => {}) callback (JavaScript, TypeScript, Java, C#, Kotlin, C++, PHP), or a Python bare except (or except Exception / BaseException) whose only statement is pass or ....

Why it matters. A failure looks like success. Nobody is told, and the code carries on with missing or wrong data.

What to do. Handle the error, propagate it, or log it with context through a server-side logger. Keep data out of the log message.

Automatic fix. Transformation for JavaScript and TypeScript: swallowed errors.

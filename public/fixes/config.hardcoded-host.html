Issue type · warning

config.hardcoded-host

What it means. Source code contains a private network address (RFC 1918 IPv4, such as 10.0.0.5 or 192.168.1.20) or a ://localhost or ://127.0.0.1 URL. Tests, fixtures and comment lines are skipped, and so are CIDR ranges.

Why it matters. The code works on one machine or network and breaks, or reaches the wrong system, everywhere else.

What to do. Read hosts and URLs from configuration (environment or a config file) validated at startup.

Automatic fix. Coming: hard-coded hosts.

Real fixes, by language

Each one is an edit sloptopop applied to a public repository, checked by the Guider, linked to the file at the commit it was made on. Committed secret values are shortened, never republished.

No real fix for this issue type has been applied to a public repository yet. sloptopop reports it, and plans a task for a person where it can.

No real fix recorded yet in: TypeScript, JavaScript, Python, Go, Java, Kotlin, C#, C, C++, PHP, PowerShell, Rust, Shell, Swift. Examples appear here only once sloptopop has fixed one in a real repository.

The sloptopop CLI and every language library are open source under MIT OR Apache-2.0, at github.com/sloptopop.

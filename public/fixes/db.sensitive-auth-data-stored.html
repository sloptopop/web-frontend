Issue type · error

db.sensitive-auth-data-stored

What it means. A column is named as sensitive authentication data: a card verification code (cvv, cvc2), card track data (track1, magstripe) or PIN data (pin_block). Booleans and check outcomes (cvc_check) are left out.

Why it matters. This data must not be kept after authorisation, not even encrypted.

What to do. Stop every writer of the column. Then overwrite and drop it in a reviewed migration, without archiving or copying it. If the column only records the outcome of a check, rename it so (…_check).

Automatic fix. None.

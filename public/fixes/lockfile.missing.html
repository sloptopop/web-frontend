Issue type · error

lockfile.missing

What it means. An ecosystem has no lockfile at the root (Go only when go.mod has requirements; Swift only when Package.swift declares packages).

Why it matters. Every install can resolve different dependency versions, including a compromised one.

What to do. Generate the lockfile with the package manager, commit it, and install from it in CI (npm ci, cargo build --locked, uv sync --locked).

Automatic fix. None.

Real fixes, by language

Each one is an edit sloptopop applied to a public repository, checked by the Guider, reviewed in its surrounding code, and linked to the file at the commit it was made on. Committed secret values are shortened, never republished.

No automatic fix for this issue type has passed review on a public repository yet. sloptopop reports it, and plans a task for a person where it can.

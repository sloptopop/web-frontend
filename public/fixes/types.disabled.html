Issue type · error

types.disabled

What it means. Type checking is switched off: tsconfig.json with "strict": false, or with no strict and no extends; a // @ts-nocheck comment; a mypy section without strict = true.

Why it matters. Type errors that the compiler would catch reach production instead.

What to do. Turn strict checking on ("strict": true, mypy strict = true), remove @ts-nocheck, and fix the errors that appear.

Automatic fix. None yet.

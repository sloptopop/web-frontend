Issue type · error

deps.circular

What it means. Modules import one another in a cycle. Covered: Rust, JavaScript and TypeScript, Python, Java and Kotlin, C and C++, Go, C# and PHP. Each cycle is reported once, at one of its files.

Why it matters. Modules in a cycle cannot be understood, tested or changed one at a time, and import order can break at runtime.

What to do. Move what both sides need into a lower module that both can import, so dependencies point one way.

Automatic fix. None yet.

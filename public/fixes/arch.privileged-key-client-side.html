Issue type · error / warning

arch.privileged-key-client-side

What it means. A privileged key can reach browser code: • error: an environment variable with a prefix the bundler inlines into client code (NEXT_PUBLIC_, VITE_, REACT_APP_, EXPO_PUBLIC_) names a service-role or secret key; • warning: a file that client components import ('use client' and what it imports) uses a service-role credential and does not import server-only.

Why it matters. Every client bundle built with the key contains it. A service-role key bypasses row-level security.

What to do. Drop the public prefix and read the key only in server-side code. Move service-role code into a module that imports server-only. Rotate the key: every bundle built so far contains it.

Automatic fix. None.

Issue type · error

tls.verification-disabled

What it means. TLS certificate verification is turned off: rejectUnauthorized: false, verify=False, InsecureSkipVerify: true, NODE_TLS_REJECT_UNAUTHORIZED=0, danger_accept_invalid_certs, danger_accept_invalid_hostnames, or CURLOPT_SSL_VERIFYPEER, false. Comment lines, tests and fixtures are skipped.

Why it matters. Anyone on the network path can read and change the traffic. The code still appears to use TLS, which hides the problem.

What to do. Fix the certificate chain, or trust the specific internal certificate authority. Never turn verification off, not even temporarily.

Automatic fix. None.

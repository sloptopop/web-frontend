Compliance

Compliance coverage per framework

For each framework: how many of its controls sloptopop's checks give evidence for, through which rules, and how far sloptopop gets with each rule in the repositories it was tested on. Evidence for a control is not compliance with it: a mapping means that a finding, or its fix, is relevant to that control. Only control identifiers are shown; the notes behind each mapping are on the coverage page.

Evidence every run produces

  • Findings

    Every finding names its rule, file and line, so an auditor can check it at the commit it was found on.

  • The plan

    Each finding becomes a step built only from a closed set of known-safe edits, or a task with a checklist and the recorded reason why no edit was made.

  • Exact edits

    Every applied edit is a byte span with the hash of the code it expects, in its own reviewable commit; nothing is written if the code has moved.

  • Verification

    After the edits: sloptopop checks again, the type checker or syntax check runs on the touched files, and the secret scan runs before and after.
